# Восстановление модели процесса по журналу событий (Process Discovery)

Решение задачи по восстановлению нормального поведения процесса заявок на закупку из синтетического журнала событий.

## Структура репозитория

- `students.csv` — исходный журнал событий (1000 процессов, 6508 событий).
- `process_discovery.py` — скрипт анализа на стандартной библиотеке Python (без внешних зависимостей).
- `variants.csv` — таблица уникальных вариантов маршрутов с частотами и долями (8 вариантов, 100% покрытие).
- `student_transitions.csv` — таблица переходов между активностями (12 уникальных пар).
- `mermaid_code.txt` — код схемы процесса в нотации Mermaid.
- `process_schema.png` — визуализация схемы (сгенерирована из `mermaid_code.txt` на mermaid.live).
- `report_task2.md` — подробный отчёт по методологии и результатам.

## Как воспроизвести результат

1. Убедитесь, что установлен Python 3.x.
2. Поместите все файлы в одну директорию.
3. Запустите скрипт:
   ```bash
   python process_discovery.py
